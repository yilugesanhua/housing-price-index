本次目标：
连续模拟12个月的数据自动更新，每一轮都必须从“统计局新数据发布日期发现”开始，直到“小程序完成数据更新并可正常使用”结束。不得只测试本地解析或上传脚本。

严格限制：

1. 只允许使用真实官方数据或已归档的官方原始页面。
2. 不得使用随机数据、演示数据、手工伪造数据或推算值补齐。
3. 只允许写入隔离测试云端，例如：
   - housing-data/preview/
   - housing-data/rehearsals/<run-id>/
4. 严禁写入：
   - housing-data/current.json
   - housing-data/releases/
   - 正式生产云函数
   - GitHub 默认分支
5. 不得推送、合并、审核、发布或部署到正式环境。
6. 测试前后都检查 Git 状态。
7. 保留测试开始前已有工作区改动。
8. 每轮失败必须记录问题，然后继续下一轮。
9. 任何数据不确定、来源不完整、解析冲突或校验失败，都必须阻断该轮更新。

每一轮必须完整执行以下流程：

一、统计局数据发现

1. 模拟等待统计局发布新的月度数据。
2. 记录模拟发布日期、统计月份和官方页面 URL。
3. 验证：
   - URL 是官方国家统计局 HTTPS 地址；
   - 页面标题和统计月份一致；
   - 发布日期可信；
   - 来源页面内容 SHA-256 稳定；
   - 页面没有被错误重定向；
   - 来源批次身份唯一。
4. 如果无法确认发布日期或来源身份，必须阻断更新。

二、原始数据获取

1. 获取官方 HTML 原始页面。
2. 保存原始页面、来源 URL、页面哈希和批次元数据。
3. 验证下载内容不是空白页、错误页、登录页或验证码页。
4. 禁止静默覆盖旧原始文件。
5. 如果下载失败，记录失败原因并阻断更新。

三、解析和标准化

1. 使用当前正式解析器解析数据。
2. 只允许识别数据契约白名单中的四类官方表。
3. 排除无关表格和错误表格。
4. 解析新房和二手房数据。
5. 解析以下面积口径：
   - 总体；
   - 90平方米以下；
   - 90至144平方米；
   - 144平方米以上。
6. 解析环比和同比指数。
7. 对官方空单元格或破折号保留合规 null。
8. 不得用0、前值或计算值填充官方未发布数据。
9. 保存来源表、行列、原始单元格定位。

四、数据正确性审计

每轮必须执行完整审计：

1. 70座城市是否全部存在。
2. 每个城市、住宅类型、面积口径组合是否唯一。
3. 是否存在重复月份或月份跳跃。
4. 是否存在城市缺失。
5. 表格类型和住宅类型是否匹配。
6. 环比、同比字段是否错位。
7. 面积段是否错位。
8. 数值精度、符号和缺失原因是否正确。
9. 每条记录是否可以回查到原始单元格。
10. 来源版本、解析器版本、审计版本和 Git 提交身份是否绑定。
11. Web 数据、共享逻辑和小程序候选输入是否逐值一致。
12. 任意一项失败都不得进入下一步发布。

五、15年完整包生成

1. 生成本轮新的完整15年数据包。
2. 覆盖范围必须是：
   - 结束月份 = 本轮目标月份；
   - 开始月份 = 结束月份向前179个月；
   - 总计180个月。
3. 每个月必须包含70座城市完整数据。
4. 验证旧月份滚动移除是否正确。
5. 验证新月份是否只新增一次。
6. 计算：
   - 数据版本；
   - 来源版本；
   - 文件大小；
   - SHA-256；
   - 记录总数。
7. 生成 manifest 和审计报告。
8. 对完整包进行重建验证，不能只验证 manifest。

六、隔离云端上传

1. 上传到隔离目录，不得接触正式目录。
2. 上传不可变完整包、manifest、撤销登记和测试指针。
3. 上传后重新下载全部对象。
4. 逐文件比较：
   - 字节数；
   - SHA-256；
   - 文件内容；
   - current 指针引用；
   - manifest 引用；
   - 撤销登记身份。
5. 确认正式 current.json 和正式 releases 目录原始字节、哈希均未变化。

七、小程序客户端更新模拟

每轮必须模拟：

1. 首次启动。
2. 首屏正常显示内置数据。
3. 后台检查云端新版本。
4. 下载完整15年包。
5. 下载过程中的页面继续可用。
6. 下载完成后自动校验。
7. 校验通过后原子切换本地缓存。
8. 校验失败时继续使用旧的已验证数据。
9. 网络中断后自动重试。
10. 存储不足时不得删除唯一可用数据。
11. 小程序重启后不能复活已拒绝的错误包。
12. 清缓存后只能使用内置安全快照或重新下载已验证版本。
13. 切换城市、筛选和图表数据不得错位。
14. 更新完成不要求用户点击“近15年”或手动重开小程序。

八、异常数据阻断测试

每轮至少注入并验证以下异常：

1. 少一个城市；
2. 少一个月份；
3. 重复记录；
4. 环比和同比错位；
5. 面积段错位；
6. SHA-256 不一致；
7. 文件被截断；
8. manifest 与完整包不一致；
9. 来源版本不一致；
10. 已撤销的数据版本；
11. 版本号倒退；
12. 下载中断；
13. 缓存写入失败。

确认所有异常都会被拒绝，且不会覆盖旧的正确数据。
