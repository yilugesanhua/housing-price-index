# 小程序稳定版本归档

稳定版本按 `v版本号_YYYY-MM-DD/` 存放在本目录。归档格式、固定版本流程和回退要求见 [`docs/MINIPROGRAM_VERSIONING.md`](../../docs/MINIPROGRAM_VERSIONING.md)。

已归档版本不得覆盖、补改或复用版本号。

现有 `v2.0.0` 至 `v2.0.2` 是旧规则下人工生成的历史归档，只读保留，不重新压缩或追填新文件。从下一次新稳定版本起，必须使用已通过本地测试的确定性候选/归档工具：从固定源码提交生成一次不可变候选ZIP和 `candidate-manifest.json`，让CI、开发者工具和双真机证据绑定该候选；全部通过后把候选ZIP原字节晋级到本目录，再生成 `SHA256.txt` 和绑定Git、数据、解析器、审计器、CI及编译证据的 `release-manifest.json`，不得重新压缩。缺少任一真实外部通过证据时，工具会失败关闭，不得新增稳定版。

归档采用两提交身份：`source_commit_sha` 是候选源码提交；后续只新增归档目录的 `archive_record_commit` 负责记录晋级，不属于ZIP输入，也不得写回归档内部形成自引用。源码提交必须是记录提交的祖先，记录提交夹带其他变更时拒绝晋级。

当前仍沿用本目录只读归档与同目录SHA-256规则；不要求受保护Git Tag或GitHub Release。
