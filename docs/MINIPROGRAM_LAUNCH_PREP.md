# 微信小程序上线准备清单

更新日期：2026-07-27

这份清单用于第一阶段小程序立项、备案、审核和试运行准备。真实数据图表技术验证已通过，正式原生适配工程位于 `apps/miniprogram/`。

## 1. 产品口径

- 产品名称：住房小二。
- 服务类目候选：工具 / 信息查询。最终以微信公众平台当前可选类目和审核结果为准。
- 服务描述：提供国家统计局70个大中城市商品住宅销售价格指数查询、比较与趋势展示，不提供房源发布、中介服务、住宅成交单价、估价或投资建议。
- 数据范围：完整70城；首页常用六城为北京、上海、广州、深圳、厦门、福州；趋势比较最多三城。
- 首发能力：查询、筛选、趋势比较、来源查看、原生分享。不接入登录、支付、广告、订阅消息、表单和第三方统计SDK。

## 3. 可直接用于备案和审核的文案

### 小程序简介

```text
查看国家统计局70个大中城市商品住宅销售价格指数，支持新建商品住宅和二手住宅的环比、同比查询及城市趋势比较。
```

### 服务内容说明

```text
本小程序提供国家统计局70个大中城市商品住宅销售价格指数的查询、筛选和趋势比较。展示指数及其变动率，不展示、估算或暗示住宅成交单价，不提供房源发布、中介服务、估价、购房推荐或投资建议。
```

### 数据来源说明

```text
数据引自国家统计局网站（www.stats.gov.cn）“70个大中城市商品住宅销售价格变动情况”。本站仅进行数据标准化和明确标注的计算展示，不是国家统计局官方网站。
```

### 隐私说明

```text
首发版本不要求用户登录，不收集姓名、手机号、身份证号、通讯录、设备联系人、支付信息或用户提交的表单内容。经用户授权后，小程序获取当前位置并通过腾讯位置服务解析所在省市，仅用于自动匹配城市；不保存精确经纬度，匹配后的城市信息和筛选状态仅保存在本机。
```

## 4. 工程立项门禁

小程序开发前必须完成以下准备：

- [x] 取得 AppID `wxf2b2a44f4c788def`，并在微信开发者工具中创建项目。
- [x] 使用真实生产数据完成 F2 Canvas 图表技术验证，并确定使用原生小程序适配层。
- [ ] 验证图表在 Android 微信和 iPhone 微信中的绘制、触摸、缩放和横竖屏行为。
- [x] 生成脚本复用 `packages/core` 的城市目录、名称和搜索别名；小程序筛选状态沿用共享数据契约。
- [x] 复用 `packages/design-tokens` 的语义令牌；不直接复制 Web DOM 或使用 WebView 包裹网页。
- [x] 由脚本生成小程序专用发布数据，不手工修改 `data/normalized/` 或 Web 发布 JSON。
- [x] 小程序客户端只读构建生成的数据，不抓取国家统计局页面。
- [x] 缺失值显示为破折号并计入缺失数；到期未更新或清单非 current 时显示醒目提示。
- [x] Web先加载摘要、再加载城市趋势分片；弱网下单个城市分片失败不会遮挡六城概览和市场位置，恢复网络或回到前台会自动重试。
- [x] 共享核心提供 `HousingViewState`、`ViewRange` 和 `DEFAULT_HOUSING_VIEW_STATE`；Web URL、未来小程序路由只负责各自平台的编码和持久化。
- [x] `packages/design-tokens/generate.mjs` 从同一令牌源生成 Web CSS、小程序 WXSS 和 JSON；CI 通过 `npm run design-tokens:check` 阻止平台令牌漂移。
- [x] 已实现原生导航、路由参数、本地缓存、原生分享和复制来源链接；试运行版不发网络请求，也不依赖 Web DOM。
- [x] 客户端以内置快照兜底，通过云函数清单和版本化云存储获取已完成哈希校验的远程数据；失败时保持最近有效缓存或内置数据。

## 8. 平台适配边界

### 可以直接复用

- `packages/core` 的城市目录、数据契约、筛选计算、温度/排名/累计变化逻辑和共享视图默认值。
- `packages/design-tokens/tokens.wxss` 与 `tokens.json`；令牌只从 `tokens.css` 生成，不在小程序项目内另起一套颜色和间距。
- 版本化静态数据结构和状态文案：加载中、部分趋势失败、离线、过期、缺失和无数据。

### 必须平台重写

- Web 的 `window`、`document`、`history`、`localStorage`、`navigator.share`、ECharts DOM 初始化和 HTML `<a>` 外链。
- 小程序使用页面路由参数承载 `HousingViewState`，使用平台缓存接口保存可选本地状态，使用原生 `onShareAppMessage` 分享，来源页通过合法业务域名或复制链接打开。
- 图表必须先用真实数据在微信开发者工具、Android 微信和 iPhone 微信验证 Canvas 清晰度、触摸命中、横屏和低端设备耗时，再决定原生 Canvas、适配图表库或分包策略。

正式工程以内置数据快照兜底，并通过现有微信云开发环境获取已校验的版本化数据；客户端不直接访问国家统计局页面，也不需要新增独立服务器。
