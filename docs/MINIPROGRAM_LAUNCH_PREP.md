## 3. 可直接用于备案和审核的文案

### 小程序简介

```text
查看国家统计局70个大中城市商品住宅销售价格指数，支持新建商品住宅和二手住宅的环比、同比查询及城市趋势比较。
```

### 服务内容说明

```text
本小程序提供国家统计局70个大中城市商品住宅销售价格指数的查询、筛选和趋势比较。展示指数及其变动率，不展示、估算或暗示住宅成交单价，不提供房源发布、中介服务、估价、购房推荐或投资建议。
```

### 数据来源说明

```text
数据引自国家统计局网站（www.stats.gov.cn）“70个大中城市商品住宅销售价格变动情况”。本站仅进行数据标准化和明确标注的计算展示，不是国家统计局官方网站。
```

### 隐私说明

```text
当前版本不要求用户登录，不收集姓名、手机号、身份证号、通讯录、设备联系人、支付信息或用户提交的表单内容。经用户授权后，小程序调用微信模糊位置接口，并将模糊经纬度通过项目云函数提交腾讯位置服务解析所在省市，仅用于自动匹配城市。项目业务代码不持久化经纬度；匹配后的 `cityId`、`locatedAt` 和筛选状态保存在本机，最长24小时。启动恢复和点击定位读取缓存时，过期、未来时间、未知城市或其他无效记录会被立即删除；来源页的“清除本地记录”会同时删除筛选、城市来源和定位缓存。微信公众平台隐私保护指引仍须按实际账号现场核对。
```

## 8. 平台适配边界

### 可以直接复用

- `packages/core` 的城市目录、数据契约/类型、已经验证的平台无关帮助函数和共享视图默认值。排名、涨跌计数、温度和累计变化目前仍由Web与小程序分别实现；D20的版本化跨平台结果契约关闭前，不得把这些计算直接迁入或宣称已经统一复用。
- `packages/design-tokens/tokens.wxss` 与 `tokens.json`；令牌只从 `tokens.css` 生成，不在小程序项目内另起一套颜色和间距。
- 版本化静态数据结构和状态文案：加载中、部分趋势失败、离线、过期、缺失和无数据。

### 必须平台重写

- Web 的 `window`、`document`、`history`、`localStorage`、`navigator.share`、ECharts DOM 初始化和 HTML `<a>` 外链。
- 小程序使用页面路由参数承载 `HousingViewState`，使用平台缓存接口保存可选本地状态，使用原生 `onShareAppMessage` 分享，来源页通过合法业务域名或复制链接打开。
- 当前图表实现使用wx-f2；替换图表库、调整Canvas承载或分包策略前，必须用真实数据在微信开发者工具、Android微信和iPhone微信重新验证清晰度、触摸命中、横屏和低端设备耗时。

正式工程只允许使用未被撤销且验证通过的内置快照或缓存兜底，并通过现有微信云开发环境获取已校验的版本化数据；不存在有效版本时显示数据暂不可用。客户端不直接访问国家统计局页面，也不需要新增独立服务器。
