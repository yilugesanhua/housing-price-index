# 第一阶段验收

以下项目必须全部满足，第一阶段才可标记完成。

## 数据

- 发布国家统计局完整70城；首页保留北京、上海、广州、深圳、厦门、福州常用六城概览。
- 2016年1月至 `dataset_as_of` 的新房、二手房、环比和同比完成完整性校验。
- 默认显示包含 `dataset_as_of` 的120个月，可切换36、60和120个月。
- 原始指数与变动率一致，缺失数据不绘制为0。
- 唯一键无重复，月份连续或显式记录缺失。
- 数据清单记录数与发布数据一致，`validation_status` 为 `passed`。
- 数据清单包含受支持的 `schema_version`、唯一 `dataset_version`、`data_status`、检查时间和 `coverage_gaps`。
- 每批官方HTML和历史引导数据都有来源URL、抓取时间、原始校验和、核验状态和 `source_batch_id`。
- 任一标准记录可通过 `source_batch_id` 和 `source_record_locator` 反查原始来源。
- 每个生产来源批次都有 `raw_archive_uri`，可恢复原始文件并校验SHA-256。
- 生产数据不引用 `unverified` 或 `sampled` 的历史引导批次。
- 修订记录保留旧值、新值、发现时间、来源批次和修订原因，不覆盖历史记录。
- 页面显示来源、统计月份、发布日期、数据状态和口径说明。
- 2026年1月基期变化有明确标注。
- 官方发布后3个工作日内完成更新；未完成时正确显示 `updating` 或 `stale` 状态。
- 缺失月份出现在 `coverage_gaps`，不伪造全为 `null` 的记录。
- 任一数据校验失败时保留上一个可用发布版本，不产生部分城市、部分月份或无效清单。
- 解析器历史结构fixture、黄金输出和已知值断言全部通过。
- 每个月份的生产记录只来自数据契约规定的四类官方表；“新建住宅价格指数”、城市对比表及无法明确识别口径的表均为零引用。
- 每月四类口径完整产生560条记录，独立 `full-record-audit-v4` 将全部记录回查到对应白名单表及原始单元格；任一月份、表类型或记录不满足时阻断发布。
- 永久保留2018年3月至12月错误覆盖的回归测试，覆盖四类表历史标题变体、表格顺序互换、重复表和冲突唯一键。

## 功能

- 新房/二手房、环比/同比可以独立查看。
- 主图最多显示三座城市，0%基准线清晰。
- 城市选择器覆盖完整70城，支持中文、完整拼音和拼音首字母搜索；常用六城置顶，其余城市按拼音首字母分组。
- 已选城市置灰并标记“已选”，选满三城时其他城市禁用；允许清空全部趋势城市，并显示可直接添加城市或恢复默认城市的空状态。
- 桌面端使用搜索浮层，移动端使用底部选择面板；打开后焦点进入搜索框，移动端焦点不离开Sheet且页面主体不滚动，关闭后焦点返回触发按钮；搜索、选择和关闭均可通过键盘或触摸完成。
- 缩放、拖动、图例显隐、Tooltip和筛选器正常工作；拖动与按钮共享缩放状态，显示当前月份范围，且图例至少保留一条趋势线。
- 累计变化图以所选范围首月为100，按月度环比指数复合到最新月份；切换主图同比时计算口径不变。
- 累计图、最新累计值和月份数据表结果一致；缺少环比数据时不跨越缺口继续计算，页面明确其不是实际元/平方米房价。
- 精确数据默认折叠，桌面使用表格，手机使用月份选择与按城市分组的数据列表。
- 70城温度按当前新房/二手房、环比/同比口径统计最新月份上涨、持平、下跌和缺失数，四类合计等于70。
- 面积筛选四档均可切换，且六城概览、市场位置、趋势图和温度历史同步更新；URL可恢复 `size` 参数。
- 重点城市可从完整70城独立选择并通过`focus`恢复；趋势列表不足三座时自动加入新重点城市，已满时只切换重点城市。主图清空时继续显示重点城市的70城、同级和省内样本位置。
- 同级城市严格使用国家统计局一二三线划分；省内对比明确限定为70城样本，单城市省级区域显示不可比较说明。
- 切换新房/二手房或环比/同比后，温度、全部排名、同级平均和省内排序同步更新，不残留上一口径结果。
- 累计图Tooltip显示“较起点”和“较高点”；“较高点”按截至当月的历史最高累计值计算，创新高为 `0.0%`，且不引用未来月份数据。
- 分享链接可以恢复趋势城市、重点城市、指标、房屋类型、面积段和时间范围；旧链接缺少`focus`时使用第一座已选城市。
- `v=1` URL参数无效时回退默认状态，超过三座城市时保留前三座并提示。
- 第一阶段使用固定分享标题和缩略图，不把动态分享卡片列为静态MVP完成条件。
- 页面包含稳定的 `title`、`description`、`og:title`、`og:description` 和 `og:image`，且文案不含投资承诺。
- 公开数据浏览不要求微信授权或账户登录。

## 响应式与兼容

- 手机端首页标题使用面向用户的住宅价格变化表述，说明文字占满可用内容宽度并明确不推算成交单价；统计月份不重复显示；筛选区为两行等宽结构，指标、住宅类型和时间范围三组宽度一致；六城排序口径位于标题下方，城市卡片辅助文字不小于12像素。
- 桌面趋势区不使用包裹全部图表的巨型圆角卡片；来源区包含数据状态，页脚不重复完整来源与口径文本。
- 至少检查375×812、390×844、768×1024、1366×768和1440×900。
- 上述视口无内容重叠、不可读截断或页面水平溢出。
- 手机端核心筛选和图表查看可通过触摸完成，不依赖鼠标悬停。
- 键盘用户可通过筛选器、月份步进器或可访问数据表获得Tooltip等价信息。
- 空数据、加载失败和加载中状态均有明确文案、稳定布局和可执行恢复动作。
- 图表拖动不拦截页面滚动、微信返回或iOS边缘返回手势，并有非手势替代控件。
- “恢复默认筛选”只恢复指标、住宅类型和时间范围；“恢复默认城市”只恢复趋势城市；本地保存清理位于来源区且不改变当前筛选。
- 横竖屏切换后图表正确重排，无空白、裁切或尺寸错位。
- HTML viewport包含 `width=device-width`、`initial-scale=1`；使用安全区时包含 `viewport-fit=cover`，且不禁用缩放。
- 电脑、平板和手机使用同一Web应用与URL体系，统计口径一致。
- 微信内置浏览器可完成最新数据查看、筛选、图表触摸、分享和来源查看。
- 至少验证一台Android和一台iPhone的微信内置浏览器；无法获得设备时记录未验证项。

## 无障碍与视觉

- 键盘可完成核心筛选，焦点顺序合理，`focus-visible` 清晰。
- 触控区域不小于44×44像素，关键目标间距至少8像素。
- 涨跌和曲线区别不只依赖颜色。
- 市场方向统一使用上涨红色、下跌绿色，错误状态不复用下跌色；全局粘性数据导航持续显示当前新房/二手房、环比/同比和面积段，趋势线明确说明颜色只用于区分城市。
- 图表提供文字摘要或数据表入口。
- 文本和关键图形满足WCAG 2.2 AA。
- 小号链接、标签和状态文字使用通过4.5:1验证的文字令牌，图表线条和控件图形至少3:1。
- `prefers-reduced-motion` 下功能完整，放大文本后核心内容不截断。
- Lighthouse Accessibility不低于90；如无法检测，记录原因和替代检查。
- 交付记录包含至少一个手机和一个电脑视口的最终截图。

## 工程与复现

- `apps/web/public/data/` 只包含平台发布所需数据，不包含原始HTML或引导数据原文件。
- 发布目录包含 `manifest.json`、完整审计数据、六城摘要、最新月560条市场快照、2,016条温度历史和70个城市分片；Web端先校验清单，只读取摘要、市场快照、温度历史和当前选择城市分片，并验证版本、范围、城市和记录数。
- 原始HTML归档可通过 `source_batch_id` 恢复并校验SHA-256，且不随生产包公开分发。
- 数据采集、更新、构建和运行方式有可复现说明。
- 以下命令全部成功退出，生产构建无错误：

```text
npm run check
npm run test:e2e
```

- UI改动按任务使用对应skill；发布前使用最新 `web-design-guidelines` 审查改动文件，并记录规则获取日期或版本及 `file:line` 结果。
- 未验证的浏览器、真机、性能或平台能力在交付记录中明确列出。
- 公开上线前完成数据转载、署名、免责声明、来源链接和纠错入口审查。
- 未接入登录、支付、表单或第三方SDK时，公开数据仍可完整浏览；接入前已完成隐私政策和SDK清单。
