# v2.3.0 双真机验收单

适用候选版本：`v2.3.0`。Android 和 iPhone 各执行一遍；任一关键项失败时不得提交微信审核，也不得开启 `AUTOMATIC_RELEASE_ENABLED`。

## 测试前确认

- 微信开发者工具项目：`70城小程序技术验证/`。
- 页面底部版本：`v2.3.0`。
- 候选版内置源数据版本：`2026-06-4fd1d1a8ff12`，数据截至 `2026-06`。
- 当前正式远程数据版本：`2026-06-e9788d0bddf3`，源数据版本为修正版 `2026-06-4fd1d1a8ff12`。候选版应在完整下载、哈希校验和70城重建通过后接受该同月同源包；已有旧源缓存仍必须拒绝并清除。
- 先上传体验版并添加测试成员；不要使用线上 `v2.0.2` 代替候选版本验收。
- 每台设备记录微信版本、系统版本、机型、测试时间和测试人。

## 放行规则

- 两台设备共24项全部通过后，才能固定 `v2.3.0` 稳定归档并提交微信审核。
- 视觉问题、Canvas空白、触摸失效、定位阻断、远程数据校验失败、离线白屏或版本号不一致均为阻断问题。
- 微信审核发布后仍保持自动生产开关关闭；完成一次发布版本的远程数据读取复核后，再单独确认是否开启自动发布。
