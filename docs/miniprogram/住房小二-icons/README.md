# 住房小二小程序图标候选

## 推荐顺序

1. `icon-01-屋檐二.svg`：房屋与“二”合为一个符号，48px 下仍清楚，最适合长期品牌化。
2. `icon-02-数字二成屋.svg`：数字 2 的远距离辨识度最高，适合分享卡片和口头传播。
3. `icon-03-双窗助手.svg`：青、橙双窗对应新房和二手房，专业含义最完整。
4. `icon-04-门牌小二.svg`：更像社区服务入口，亲切但行业辨识略弱。
5. `icon-05-房屋笑脸.svg`：助手人格最明显，传播友好但风格相对活泼。

## 设计约束

- 图形安全区约为画布的 68%，适应微信圆形或圆角方形裁切。
- 不使用文字、钥匙、金币、上涨箭头或楼盘剪影，避免地产中介和投资工具联想。
- 主色沿用项目令牌：蓝 `#007AFF`、深青 `#176C79`、橙 `#D07A34`。
- SVG 为主源文件；PNG 分别导出 1024px 和 144px，便于提交与小尺寸评估。
