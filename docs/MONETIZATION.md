# 商业化原则

## 底线

变现不能损害数据工具的中立性、基础可用性和来源透明度。最新公开数据、基础趋势、统计口径和来源链接不得通过强制登录、诱导分享或遮挡广告才能访问。

## 候选模式

按优先级验证：

1. 个人增值订阅：关注城市、更新提醒、保存比较、面积段分析、修订提醒、高清图片或CSV导出、定制月报。
2. B2B服务：嵌入图表、规范化数据接口、定制城市报告和白标组件。
3. 一次性数字产品：专题报告、城市对比报告和机构版导出。
4. 克制广告或品牌合作：仅使用当前平台允许的官方广告能力或明确标注的赞助位。

建议分层：

```text
免费层      最新数据、近10年基础趋势、70城三城比较、来源与口径
个人订阅    关注城市、提醒、保存比较、面积段分析、导出和月报
机构服务    嵌入图表、数据接口、定制报告、白标组件
广告合作    页面自然停顿位置的明确广告位，不进入核心图表区
```

## 账户能力分期

- 第二阶段的关注城市和保存比较使用本地存储，不要求登录，不承诺跨设备同步。
- 订阅提醒先用意向登记验证，不在没有需求证据时建设完整账户和支付系统。
- 第三阶段才评估账户同步、微信订阅消息、支付和跨设备恢复。
- 用户拒绝授权、登录服务故障或支付服务故障时，公开数据浏览仍可用。

## 实验门槛

每项商业化实验在开发前登记：

```text
hypothesis        用户问题和付费假设
target_user       目标用户
offer             权益和价格表达
primary_metric    唯一主要指标
guardrail_metrics 投诉、退出、页面性能、基础功能使用等保护指标
observation_window 观察周期
success_threshold 成功阈值
stop_condition    停止或回滚条件
decision          expand、iterate或stop
```

阈值必须在实验开始前确定，不能看到结果后追改。第一轮优先用订阅意向、候补名单、机构咨询表单等低成本方式验证，不展示虚假人数、虚假限时价格或无法兑现的权益。

## 展示与交互约束

- 广告和赞助与数据结论在视觉及语义上分离，并显著标注“广告”或“赞助”。
- 广告不覆盖筛选器、图表、Tooltip、来源说明或主要操作。
- 不使用开屏广告、强制倒计时、虚假关闭按钮、连续弹窗、默认勾选或分享解锁。
- 付费功能使用明确的“升级查看”或“申请机构服务”入口，不用模糊遮罩、假锁图标或遮挡公开数据制造点击。
- 付费页清楚展示权益、价格、计费周期、自动续费状态、取消方式和退款或客服入口。
- 不接受付费修改城市排名、数据口径、图表比例或编辑结论。
- 商业报告不得包装成投资建议或承诺房价走势。

## 隐私与合规

- 不出售个人信息、浏览记录、关注城市或设备标识。
- 不以授权换取基础数据访问，只采集完成明确功能所需的最少数据。
- 商业化埋点需要字段清单、用途、保留期限、访问权限和关闭方案。
- Web支付、微信支付、小程序虚拟商品、订阅消息和广告组件上线前，核验当时有效的平台规则、类目资质、审核和隐私要求。
- 上线收集表单、埋点、账户或支付前，必须准备并审核：隐私政策、用户协议、第三方SDK清单、数据收集与保留清单、删除或注销流程、客服入口。
- 在提供数据接口、白标组件或商业报告前，确认国家统计局数据转载、署名和商业使用要求，并在合同及输出中保留来源和本站计算标识。
- 广告、支付、登录和机构服务均通过独立Feature Flag控制，可单独关闭。

## 第一阶段公开上线门槛

即使尚未变现，公开Web MVP上线前也必须完成：

- 确认国家统计局数据转载、署名和链接要求。
- 确认原始HTML只作内部审计归档，不随生产包公开再分发。
- 页面明确声明“本站不是国家统计局官方网站”。
- 本站计算指标与官方原始指标在命名和视觉上清楚区分。
- 发布数据来源说明、免责声明和联系纠错入口。

若第一阶段接入访问分析、意向表单或任何第三方SDK，还必须在上线前提供隐私政策、SDK清单、采集字段、用途、保留期限和关闭方式。
