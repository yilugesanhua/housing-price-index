# 页面体验审查记录

日期：2026-07-19

## 审查范围

- 任务：普通用户查看城市概览、市场位置、长期趋势、修改筛选和添加趋势城市。
- 视口：1440×900、430×932、320×720、844×390。
- 证据：本轮内置浏览器实际截图和DOM状态；截图见同目录 `01` 至 `07`。
- 规则：Product Design combined audit、仓库 `PRODUCT.md` / `DESIGN.md`，以及 2026-07-19 获取的 Vercel Web Interface Guidelines。

## 结论

Web MVP 的主流程已具备可用性：数据口径清楚，移动端可以在粘性导航中直接改四项筛选，市场位置和趋势图层级清晰，城市选择面板适合微信触摸操作。本轮修复了摘要负值符号、分享回退、重复筛选DOM和340px以下选择器可读性；当前剩余风险主要是微信真机、小程序和正式分享链路尚未验证。

## 2026-07-19 本轮复查与修复

- 摘要负值改为无符号绝对值文案，避免出现“下降 +5.5%”的语义冲突；新增核心格式化单测。
- 分享流程改为系统分享、剪贴板、页面内兼容复制三级回退；取消原生 `prompt`，按钮名称改为“分享当前页面”；桌面与移动端E2E覆盖系统分享和剪贴板回退。
- 桌面端和移动端不再同时渲染两套筛选DOM：桌面保留完整筛选面板与只读口径，手机及低高度横屏保留粘性快速筛选；减少重复无障碍名称和隐藏交互入口。
- 320–340px改为两列两行快速筛选，选择器正文保持16px；重点摘要在极窄屏改为上下布局，粘性导航滚动偏移同步增加。
- Impeccable detector（`App.tsx`、`styles.css`）结果为空；lint、typecheck、17项Web单测通过；针对本轮变更的6项桌面/移动端E2E通过。

## 主要风险

### 已解决 320px 窄屏水平溢出

页面最小宽度、图表包裹层和极窄屏快速筛选均已调整；响应式矩阵重新测得页面和导航水平溢出为0。

位置：`apps/web/src/styles.css:3`。

回归覆盖：`responsive.spec.ts` 的320×720视口断言。

### P1 微信真机和小程序仍未验证

仓库目前没有 `apps/miniprogram/`，本轮只能证明Web在Chromium/WebKit和内置浏览器模拟视口下的表现，不能证明微信Android/iPhone真机的Canvas触摸、分享、来源跳转、安全区和性能，也不能证明原生小程序包体积与图表方案。

位置：`docs/ACCEPTANCE_EVIDENCE.md:62-63`、`apps/miniprogram/`不存在。

建议：Web首发前完成一台Android和一台iPhone微信真机验收；小程序立项前按PRODUCT中的真实图表技术验证门槛单独建适配层。

### P1 iOS安全区与粘性导航偏移缺少真机证明

顶部栏使用了 `env(safe-area-inset-top)`，但粘性导航仍固定 `top: 58px`。刘海屏上顶部栏实际高度增加时，导航可能与顶部栏重叠；本轮无法在正式iPhone微信中证明没有重叠。

位置：`apps/web/src/styles.css:16`、`apps/web/src/styles.css:51`、`apps/web/src/styles.css:322`。

建议：把顶部栏实际高度抽为安全区感知的变量，或至少使用 `top: calc(58px + env(safe-area-inset-top))` 并在真机验证锚点滚动。

### 已解决 桌面端重复筛选入口

桌面端粘性导航现在只读显示当前口径，四项可编辑筛选只在完整筛选面板出现；手机和低高度横屏只渲染粘性快速筛选。

位置：`apps/web/src/App.tsx:311-347`。

验证：DOM中按断点只保留一套筛选入口，避免重复无障碍名称。

### 已解决 移动端快速选择器字号偏小

常见手机和低高度横屏选择器正文为16px；320–340px改为两列两行，不再依赖缩小字号塞入四列。

位置：`apps/web/src/styles.css:180`、`apps/web/src/styles.css:325`。

验证：响应式E2E断言选择器字号不小于16px，320px断言为两列。

### P2 手机横屏进入桌面筛选布局

844×390横屏原先按宽度进入桌面布局，首屏大部分高度被标题和完整筛选面板占用。本轮已增加宽度≤900且高度≤600的紧凑布局条件，让手机横屏继续使用移动筛选与内容重排。

位置：`apps/web/src/styles.css:308`。

建议：增加“宽屏但低高度/触摸设备”规则，让手机横屏继续使用紧凑筛选导航；不要只按宽度判断设备形态。

## 已确认的优点

- 首屏说明明确区分住宅价格指数与成交单价，来源与发布日期可见。
- 430px手机首屏不需要上滑即可修改四项核心筛选；筛选状态写入URL。
- 市场位置只显示一个重点城市，排名、同级和省内比较语义清楚。
- 长期趋势支持空状态、城市上限、缩放、图例显隐、精确数据和累计变化解释。
- 城市选择底部面板有搜索、已选状态、完成按钮、焦点回收和滚动锁定，适合微信触摸。
- 当前页面未禁用缩放，图标按钮有可访问名称，加载/错误/撤销状态使用了语义状态和实时播报。

## 证据限制

- 本轮没有在正式Android/iPhone微信中操作，不能宣称微信真机兼容或小程序兼容已完成。
- 对比度、键盘、屏幕阅读器和Canvas触摸仍应以自动化/真机测试补充，截图本身不能证明完整WCAG合规。
