# 小程序自动定位配置

首页定位入口已经接入 `wx.getLocation`、云函数逆地理编码和70城匹配逻辑。未配置云环境时，用户仍可点击城市名称手动选择。

## 控制台配置

1. 在腾讯位置服务控制台创建应用和 WebService API Key，并启用逆地址解析。
2. 在微信开发者工具中为当前小程序创建或选择云开发环境。
3. 将云环境 ID 写入 `apps/miniprogram/config/location.js` 的 `cloudEnvId`。
4. 在云函数 `reverseGeocode` 的环境变量中新增 `TENCENT_LBS_KEY`。不要将 Key 写入代码、提交到仓库或发送到聊天中。
5. 在微信开发者工具中右键 `cloudfunctions/reverseGeocode`，选择“上传并部署：云端安装依赖”。该函数没有第三方依赖。
6. 确认微信公众平台的用户隐私保护指引已声明定位用途，并在真机上完成首次授权、拒绝授权和重新定位测试。

## 运行规则

- 分享链接中的重点城市优先，不会被自动定位覆盖。
- 用户手动选择城市后，下次打开不再自动覆盖；点击定位图标可重新定位。
- 自动定位结果缓存24小时，缓存期间不重复调用逆地理编码。
- 精确匹配70城时使用定位城市；非70城按所在省份选择70城样本中的省会城市。
- 定位失败、用户拒绝授权或省份无法匹配时保留当前城市，并允许手动选择。

## 凭据安全

`TENCENT_LBS_KEY` 只存在于云函数环境变量。小程序包和云函数源码都不得包含真实 Key。腾讯位置服务控制台还应为 Key 设置可用服务和调用配额限制。
